## Crucial provenance and evidence limitations

1. The three CSVs were generated by the user's Windows full audit at `D:\paper\CellCharter_reproduction\results\e5b_external_v1\phase_audit_v1\audit_20261122T030849Z_17404`, then uploaded to ChatGPT. Their original SHA256 hashes are preserved, including Windows CRLF line endings; the verified GitHub copies are identical.
2. The user's terminal output establishes successful **local audit-script execution**, not independent access from GitHub to 360 source prediction CSVs, model weights, or annotation source. The original **audit_report.json is now archived** in this release; raw prediction files and reference labels have **not** been uploaded. This release permits replication of the CSV-level patient aggregations, not reconstruction of original scores from raw labels and raw prediction files.
3. Only **six patients** count as independent biological sampling units. Seeds, spots, and individual model predictions are technical or nested observations. No result here supports n=360 independent biological replicates, clinical validation, significance claims, or direct transfer of a DLPFC-trained model to breast cancer tissue.
4. `k_blind` (unlabeled K selection) and `oracle_k` (reference category count informed) must be tabulated separately. Oracle-K is not a mathematical performance upper bound. BANKSY and BayesSpace use their original counts/representation, not the common scVI 5D for GMM/Leiden. BayesSpace K-blind selected the frozen search upper bound q=10 for all 18 seeds/patients; this must be disclosed.
5. **Do not retroactively preregister an analysis.** The 2026-11-21 original frozen experiment protocol controls what was specified **before** running experiments; the review and figures in this folder were created **after reading results**. The review is an archival snapshot. Any sentence inside it claiming the results had not yet been pushed to GitHub reflects the snapshot's creation time and is now superseded by this release.
6. Do not call the spatial representation a novel algorithm or assert comprehensive superiority to baselines without examining closely overlapping prior literature, frozen protocol, method comparability and actual negative results.
