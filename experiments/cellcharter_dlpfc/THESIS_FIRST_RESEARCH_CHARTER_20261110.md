# 第三篇 CellCharter 研究目标与验收约定（2026-11-10）

> 本文件记录用户明确提出并与助手讨论达成的最新目标调整。它是**研究管理与论文写作要求**，不是已获得新数据、学校学位要求官方文件或已批准的创新性结论。后续如与旧研究计划“必须独立产出SCI方法文章”发生冲突，以本文件为优先研究目标；正式学位要求和导师意见需要核验。

## 1. 实际首要目标

第三篇研究的**首要交付物**是硕士毕业论文中的一章真实、完整、扎实的CellCharter空间聚类实证研究。实验与规范可以按普通SCI论文/会议方法论文标准准备，但**并不要求研究第三篇必须先独立发表SCI论文才能算工作完成**，除非学校培养要求或导师另有明确规定。争取完成一篇可投稿的普通SCI增量方法论文是附加目标、不是无限探索的硬性前提。

### 论文优先关注的组成部分

1. **摘要**：简练陈述研究动机、任务、方法、数据与实证结论，避免拔高创新和结论。
2. **研究背景与意义**：为什么空间转录组需要空间域识别；CellCharter及多尺度空间邻域聚合的现有用途和未确定适用条件。
3. **方法、设计与实验充分性**：清楚记录数据来源、参考标签、Oracle-K、scVI与CellCharter实现、空间图、特征块对照、GMM及评价方法；提供足够的公平对照、消融、跨切片/供体结果、必要稳定性诊断与负例；实验“尽量充实”不等于灌水或追求无关实验数量。所有表格/图必须由实际结果生成，按供体正确处理依赖结构。
4. **分析与讨论**：解释结果的适用条件、可能的机制和混杂（不能把假设写成已证实因果）、已有工作重叠及真实局限。
5. **总结**：仅总结已核实的工作、发现、价值、失败和局限；不保证普遍改进。

## 2. 两条并行路径

### A. 保底毕业论文章节（必须持续推进）

即使最后无法找到稳定的结构性缺陷、无法开发新方法，也应将已有的有效研究过程转换为有内容的章节，而不是从头推倒：
- 数据基础：DLPFC 12张Visium切片，来自3位供体；供体2 Oracle K5，其余K7，标注来源不同需要披露。
- 特征和流程：公开CellCharter/scVI成熟基线、多尺度25D缓存、空间图检查、冻结15D A/B方案（A:L0+L1+L2，B:L0+L1+L4）。
- 评价证据：12片整体ARI/NMI/边界F1等对照；新10片真实结果完整、且Barcode和选定指标已由用户Windows重算通过；新10片F1改善4/10，全12片6/12。
- 多尺度原有消融、负结果、供体差异、边界TP/FP/FN与误报及后续必要的稳定性诊断和可视化，组织成“研究问题—方法与设计—结果—解释—局限”的完整章节。
- 以经核实原始结果为证据来源；旧2片开发结果与后10片扩展结果分开披露，不把spot、边、seed或切片视为独立供体。
- 由于本研究目前仅3位供体、不同参考标签粒度，不能承诺所有外推、显著性检验或创新主张。
- **保底是研究计划，不是学位审核保证**；是否足以支撑硕士学位论文、学位论文是否还需额外独立研究内容及是否必须发表论文，须由学校文件/导师确定。

### B. 争取SCI小创新（投入有限、可停止）

- 先做低成本关键问题诊断（例如GMM运行间稳定性），只在确有异常且有实质未解决问题时设计**一个**最小改进；优先复用缓存，避免重新训练scVI。
- 以成熟文献和现有可复用方法为起点，公平比较最简单替代方案、原版CellCharter和类似已有方法。仅新增明显有效且有可核实实质区别的机制，才能称为候选创新。
- 提前锁定参数/种子/成功与停止标准，全面保留负结果，不追逐最好看的单次seed/尺度组合。
- 如果前期证据显示没有稳定效果、已经被成熟多重启方法充分解决、或成本超出预算，则停止创新探索，把可信结果写入毕业论文章节。

## 4. 论文写作与实施约束

- 写作与必要实验可并行：摘要/结果最终稿必须等实际数据，方法与设计可以先写真实已执行部分；不伪造数据、方法、文献、统计和“新算法”。
- 本地实验由用户Windows PowerShell手动执行。AI一次只给一个可复制命令或短步骤，说明目的、预期与失败处理，等用户返回日志。
- GitHub Connector可协助维护笔记/协议/脚本，但未上传的Windows模型与CSV不因GitHub笔记而得到备份。
- 优先轻量、文献与数据双证据、可复现的增量成果；研究目标是**“创新争取，毕业优先；实验充分，但不无限探索”**。
